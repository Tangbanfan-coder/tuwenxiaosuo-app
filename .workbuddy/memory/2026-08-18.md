## 修复：插画模式选择菜单溢出屏幕问题
- **文件**：`src/components/Composer.tsx`、`src/styles.css`
- **问题**：配图模式下拉菜单（无图/按需/自动）使用 `bottom: calc(100% + 8px)` 向上展开，但 Composer 位于页面底部，导致菜单溢出屏幕
- **方案**：添加智能方向检测（flip positioning）
  - 新增 `menuFlipped` state 跟踪展开方向
  - 新增 useEffect 在菜单打开时检测上方/下方可用空间
  - 当上方空间不足（< 170px）且下方空间充足时，自动改为向下展开
  - 新增 `.illustration-mode-menu-flipped` CSS 类实现向下定位

## 修复：交互动画缺失问题（全面排查与修复）
- **背景**：用户反馈设置页面有入场动画但二级页面切换无动画，体验割裂

### 已修复的组件

| 组件 | 问题 | 修复方案 |
|------|------|----------|
| **SettingsDrawer** | 页面切换（home ↔ writing/memory/appearance/providers）无过渡 | 添加 `pageTransitionKey` state + `@keyframes settings-page-in`（右滑+淡入） |
| **自定义画风编辑器** | 展开/收起时突然出现/消失 | 改为始终渲染 + max-height/opacity CSS transition |

| **ComposerAssetsMenu** | 素材面板缺少退出动画 | 使用 `usePresence` hook + 添加 closing 类名和 CSS 动画 |
| **ReasoningEffortQuickControl** | 下拉菜单只有进入动画 | 使用 `usePresence` hook + 添加 `theme-menu-out` 退出动画 |

### 新增的 CSS 动画
- `@keyframes settings-page-in` - 设置页面切换进入动画
- `@keyframes theme-menu-out` - 小菜单退出动画（复用于 reasoning-effort-quick-menu）

### 技术要点
- 统一使用项目已有的 `usePresence` hook 管理退出动画
- 遵循项目动画变量规范（`--motion-panel`, `--motion-exit`, `--motion-enter-ease` 等）
- 保持与现有动画风格一致（cubic-bezier 缓动、合理的持续时间）
